운송장 조회 프로그램 사용 매뉴얼

아르바이트 교육용 · 다올커머스

목차 1. 프로그램 열기2. 매일 하는 일3. 주문 등록 4. 송장번호 입력5. 상태 읽는 법6. 수정·삭제 7. 매입처 회신 관리8. 다운로드9. 자동 조회10. FAQ·주의사항

이 프로그램은 주문 건들의 택배 배송 상태를 한 번에 조회·관리하는 도구입니다. 주문을 등록하면 택배사(롯데·CJ대한통운·한진·우체국·로젠)에 자동으로 상태를 조회해 완료/배송중/지연 등을 표시합니다. 데이터는 Google Sheets에 자동 저장되어 다른 PC와 실시간 공유됩니다.

1. 프로그램 열기와 화면 구성

  1. 받은 index.html 파일을 더블클릭해 브라우저(크롬 권장)로 엽니다.
  2. 열리면 대시보드가 먼저 표시됩니다. 오른쪽 아래 "시트에서 N건 불러왔습니다"가 뜨면 정상입니다.
화면 영역내용
검은 헤더전체 / 배송완료 / 배송중 / 배송지연 / 출고전 / 송장미등록 / 조회실패 건수 요약
상단 바 1줄보기 전환(대시보드·배송 목록) + 상태 필터 버튼(건수 표시)
상단 바 2줄전체 조회 · 자동 조회 · + 단건 등록 ↑ 파일 업로드 ↓ 템플릿 ↓ 보고서 ↓ 회신요청서
대시보드상태 분포, 배송지연 위험도(3·5·7일), 은행명별·매입처별 회신/완료율, 14일 추이
배송 목록건별 목록 — 검색·필터·수정·삭제는 모두 여기서

2. 매일 하는 일 (권장 순서)

① 전체 조회→ ② 대시보드 확인→ ③ 신규 주문 업로드→ ④ 미회신 독촉(회신요청서)→ ⑤ 회신 반영(업데이트 업로드)→ ⑥ 보고서 다운로드
순서할 일방법
1배송 상태 갱신상단 전체 조회 클릭 (배송완료·송장 없는 건은 자동 제외)
2대시보드 확인배송지연 위험도(주의/경고/심각)와 송장미등록 건수 확인
3신규 주문 등록↑ 파일 업로드 → "신규 등록" 모드 (또는 단건 등록)
4미회신 독촉송장미등록 탭 확인 → ↓ 회신요청서 → 매입처 발송
5회신 반영매입처 회신 파일을 ↑ 파일 업로드 → "송장번호 업데이트" 모드
6보고↓ 보고서 다운로드로 현황 엑셀 생성
참고전체 조회는 수백 건 기준 2~3분 걸립니다. 진행 중에는 새로고침하거나 창을 닫지 마세요.

3. 주문 등록하기

3-1. 엑셀 파일로 한 번에 등록

  1. ↓ 템플릿 다운로드로 양식을 받아 작성합니다.
    주문일 / 은행명 / 지점명 / 고객명 / 품번 / 품명 / 배송타입 / 다올직원 / 매입처 / 수량 / 보내는이 / 받는이 / 고객주소 / 전화번호 / 택배사 / 운송장번호 / 비고
  2. ↑ 파일 업로드 → 신규 등록 모드 → 파일을 끌어다 놓기 → 시작
  3. 송장번호가 있는 건은 자동 조회, 없는 건은 송장미등록으로 등록됩니다.
  • 수량 = 송장 1건당 수량입니다. 주문 총수량은 자동 합산됩니다.
  • 한 주문에 송장이 여러 개면 운송장번호 칸에 쉼표(,)로 이어 쓰면 행이 자동으로 나뉩니다.
    예: 6934-8452-0756, 6934-8452-0760
  • 컬럼 순서는 바뀌어도 되고, 예전 양식(주문처·담당자·채널·수하인/수취인)도 그대로 인식됩니다.
주의번호와 번호 사이에 쉼표가 없으면 하나의 잘못된 번호로 붙어버립니다. 반드시 쉼표로 구분!

3-2. 한 건씩 등록

  1. + 단건 등록 클릭 → 항목 입력 → 등록 및 조회
  2. 송장번호를 비워두면 송장미등록으로 등록되고 나중에 채울 수 있습니다.

4. 송장번호 입력하기 — 3가지 방법

방법언제 쓰나사용법
목록에서 바로 입력한두 건 빠르게미등록 건의 운송장번호 칸에 번호 입력 후 Enter → 즉시 등록·조회
상세/수정 화면정보도 같이 고칠 때행 더블클릭 → 운송장번호 입력 → 전체 저장
엑셀 일괄 업데이트매입처 회신 반영↑ 파일 업로드 → 송장번호 업데이트 모드 → 회신 파일 업로드
  • 어느 방법이든 쉼표로 여러 개 입력하면 같은 주문 정보로 행이 자동 분리됩니다.
  • 업데이트 모드는 주문일+은행명+지점명+품번+품명+보내는이+받는이가 같은 건을 찾아 번호를 채웁니다.

5. 배송 상태 읽는 법

상태뜻조치
배송완료고객에게 전달 완료없음
배송중택배사가 배송 진행 중 (집화완료·배달출발 포함)전체 조회로 갱신
출고전송장번호는 있으나 아직 택배사 접수 전1~2일 내 자동 해소
송장미등록송장번호가 아직 없음 (미회신)매입처에 회신 요청
배송지연출고(또는 등록) 2일 지나도 미완료 · 미등록 포함위험도 확인 후 확인 전화
조회실패택배사 조회가 계속 실패상세에서 다시 조회, 사유 확인
사고반송·파손·분실 등담당자에게 즉시 보고

목록 화면 읽기

  • 2/3 · 완료1 묶음 배지 — 같은 주문에 송장 3개 중 이 행은 2번째, 완료 1개. 마우스를 올리면 형제 송장 목록이 보이고, 전부 완료되면 3/3 · 완료3 초록색이 됩니다.
  • 총수량 — 같은 주문 송장들의 수량 합 (자동 계산)
  • 받는이 아래 작은 숫자 = 연락처 · 행 맨 앞 ▸를 누르면 배송주소·연락처(복사 버튼)·고객명·품번·배송타입이 펼쳐집니다
  • 행 전체가 노란색이면 배송지연 건

찾기

  • 상단 상태 버튼 클릭 → 해당 상태만 표시 (검색 조건은 초기화됨)
  • 검색 대상: 받는이·보내는이·품명·송장번호·은행명·지점명·고객명·매입처·다올직원·연락처
  • 전체 은행명 / 전체 다올직원 드롭다운, 주문일 기간으로 좁히기 가능

6. 수정과 삭제

상세/수정 — 여러 건 한 번에

  1. 수정할 행들을 체크 → 상세/수정 클릭 (한 건이면 행 더블클릭이 빠름)
  2. 엑셀처럼 가로로 펼쳐진 표에서 원하는 칸을 직접 수정
  3. 전체 저장 — 바뀐 행만 저장되고, 송장번호가 새로 생기면 자동 조회
  • 1건만 열면 아래에 배송 진행 내역(집화→배달)이 표시됩니다. 비어 있으면 자동으로 불러옵니다.
  • ↻ 선택행 다시 조회 — 열린 건들만 강제 재조회 (조회실패 복구용)
  • 송장번호를 지우고 저장하면 송장미등록·출고전으로 되돌아갑니다.

삭제

  1. 삭제할 행 체크 → 삭제 (n) → 확인
주의삭제하면 Google Sheets에서도 지워지며 복구할 수 없습니다. 전체선택+삭제 = 전체 삭제이니 특히 조심!

7. 매입처 회신 관리 (미회신 독촉)

송장미등록 탭 확인→ 회신요청서 다운로드→ 매입처별 파일 이메일 발송→ 회신 파일 수신→ 송장번호 업데이트 업로드
  1. 상단 필터 [송장미등록] 클릭 → 미회신 건 확인
  2. ↓ 회신요청서 클릭 → 매입처별로 파일이 하나씩 다운로드됩니다.
    송장회신요청_가나상사_2026-09-02.xlsx — 브라우저가 "여러 파일 다운로드 허용"을 물으면 허용
  3. 각 파일을 해당 매입처에 발송 — 택배사·송장번호 칸을 채워 회신해 달라고 요청
  4. 회신 파일을 ↑ 파일 업로드 → 송장번호 업데이트 모드로 업로드 → 자동 매칭·조회
참고대시보드의 "매입처별 송장회신율" 표에서 어느 매입처가 회신이 늦는지 한눈에 볼 수 있습니다.

8. 다운로드 기능

버튼내용
↓ 목록 다운로드지금 화면에 보이는(필터·검색 적용된) 목록을 엑셀로 저장
↓ 보고서 다운로드요약(총주문·회신·완료) + 일별 + 은행명별 + 매입처별 현황 보고서
↓ 회신요청서미회신 건을 매입처별 파일로 생성 (7번 참고)
↓ 템플릿 다운로드신규 등록용 빈 양식

9. 자동 조회

  • 상단 바의 자동 조회: 주기(분)를 입력하고 켜기 → 즉시 1회 조회 후 주기마다 자동 갱신
  • 모든 건이 배송완료되면 자동으로 꺼집니다. 자리를 비울 때 켜두면 편리합니다.

10. 주의사항 · 자주 묻는 질문

  • 업로드·조회 진행 중에는 창을 닫거나 새로고침 금지. 업로드 창은 진행 중 닫기가 막혀 있고, 새로고침 시 경고가 뜹니다.
  • Q. 삭제했는데 다시 보여요 — 새로고침 후에도 보이면 한 번 더 삭제하세요. 이후에는 다시 나타나지 않습니다.
  • Q. 배송완료됐다는데 "배송지연"에 있어요 — [전체 조회]를 실행하세요. 상태는 마지막 조회 시점 기준입니다.
  • Q. "조회실패"가 계속 떠요 — 행을 더블클릭해 실패 사유를 확인하고 [선택행 다시 조회]를 눌러보세요. 반복되면 관리자에게 송장번호와 함께 알려주세요.
  • Q. 같은 파일을 두 번 업로드했어요 — 이미 등록된 송장번호·주문은 자동으로 중복 제외됩니다.
  • Q. 다른 PC에서도 보이나요 — 네. Google Sheets에 저장되어 같은 프로그램을 쓰는 모든 PC에서 공유됩니다.
