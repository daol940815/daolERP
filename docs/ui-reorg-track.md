## 배경

회계·경영 모드 사이드바가 41개 링크(정리 도구 17개에 작업·리포트·구 화면 혼재)라
원하는 기능을 찾기 어렵다는 사용자 지적. 회사 조직(CLAUDE.md "회사 조직")에 맞춰
재조정한다.

- **2026-09-29 사용자 피드백 (재배치안 1차 검토)**:
  - 선택 화면·전환 링크에서 **'모드'라는 단어를 쓰지 않는다** (선택 화면 자체는 유지).
  - **회계·재무와 인사·총무는 별도 영역**으로 나눈다 ("경영지원 모드" 하나로 묶지 않음).
  - **권한의 목적 = 임직원이 회계·재무 자료를 임의로 열람·수정하지 못하게 하는 것.**
  - 권한은 **마스터 계정이 직원별로 조회 / 수정(작성)을 부여**한다 (팀 기본값이 아니라 개인별).
    경영지원팀은 회사 업무 대부분에 관여하므로 팀 단위 틀이 맞지 않음.

- **2026-09-29 확정 (2차 검토)**:
  - 영역 **4개**: **영업·주문**(전 직원 기본 화면, 구 "직원 워크스페이스") / **회계·재무** /
    **인사·총무** / **경영 현황**(조회 전용, 대표·부사장).
  - 선택 화면 제목 **"업무 선택"**, 각 칸은 **제목만**(부가 설명 없음). '모드' 단어 사용 금지.
  - 권한: 마스터 계정이 직원별로 영역(그룹) 단위 **없음/조회/수정** 부여.
    **엑셀 다운로드는 조회 권한자도 허용.**
  - **급여 정보·결제정보는 별도 잠금**(영역 권한과 무관하게 개별 허용해야 열람).
  - **마스터 계정 3개**: ERP 총괄(daol825) · 오철준 대리(ERP 제작 진행 담당) · 사장님.
    마스터 = 전 영역 수정 + 권한 부여. 마스터 지정·해제는 마스터만, 자기 자신 해제 불가.

  묶고, 누가 보느냐는 **직원별 권한 데이터**로 둔다. 담당 업무 변경 = 직원·계정 관리에서
  권한 변경(배포 없음). 승인 라인도 권한 데이터.
- **2026-09-29 구 화면 폐기 실행**: 매출처 관리(구) `/customers` · 매입처 관리(구) `/vendors` ·
  거래처 상세(구) `/vendors/[id]` — 페이지를 리다이렉트 스텁으로 교체(옛 주소 → 허브),
  구 상세로 가던 링크 4곳 허브로 교체, 전용 API 4개 삭제. main d790dee.
- 한정호 사원(영업지원팀, 신입)은 직원 마스터·계정이 없음 — **사용자가 직원·계정 관리에서
  등록** (시스템 작업 아님).
- **인사 관리는 처음부터 설계**(사용자, 2026-09-29): 현재 근태·휴가·직원 계정만 존재.
  범위 후보 — 직원 마스터 확장(팀·고용형태·권한), 명절 아르바이트(근무일지·급여 계산·
  근로계약서·보안서약서), 전체 스케줄(업무·휴가 캘린더). 인사 트랙(200번대) 과제로 이관 —
  우선순위·범위는 사용자 결정 대기.

## 재배치안 골격 (재배치안 구조도 참조 — 사용자 검토 대기)

모드 2개: **직원 워크스페이스**(전 직원, 권한별 그룹 노출) / **경영지원 모드**(경영지원팀·대표).
"직원 관리 모드"는 워크스페이스·경영지원으로 흡수.

- 워크스페이스: 내 업무 / 고객·영업 / 주문·발주 / 수금·정산 작업 / 팀 관리
- 경영지원: 경영 현황(대표 화면) / 회계·재무 작업(업무 용어) / 결산·세무 자료(세무사 대조,
  기본 접힘) / 인사·총무 / 점검·정리 도구(기본 접힘)

권한 항목 초안 11개: customers.view / orders.write / collections.work / invoices.issue /
payables.work / approve / mgmt.view / acct.work / acct.close / hr.admin / tools.
팀 기본값: 영업팀 = customers.view·orders.write / 영업지원팀 = + collections.work·
invoices.issue·payables.work (팀장 +approve) / 경영지원팀 = mgmt.view·acct.work·acct.close·
hr.admin·tools·payables.work (총괄부사장 +approve) / 대표 = mgmt.view·approve(+전체 조회).
