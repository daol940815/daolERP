# 매출처 고객관리 트랙 (투트랙: 지점별 + 담당자별)

작성일: 2026-08-24 · 상태: **이행 완료 (1·2단계 실행·검증 종료)**
관련: 매출처 허브(100번대) · 인물 마스터 `contacts`+`contact_assignments`(A안 확정)

## 확정 사항 (사장님)

1. **투트랙 관리**: 고객관리(매출처)는 지점별 + 매출처 담당자별 두 축으로 관리한다.
   - 지점별 = `vendors`(은행·지점 단위) — 매출처 허브
   - 담당자별 = `contacts`(인물) + `contact_assignments`(배정 이력)
2. **정답 데이터**: 영업지원팀이 실무 확인으로 정리한 고객관리 문서가 기존 ERP 추출
   데이터보다 정확하다. 상이하면 문서 기준으로 정리한다.
3. **반영 방식**: 갈아엎기가 아니라 **병합·연결**로 흡수한다 (원본 불수정 원칙).
   기존 연결(카드번호·세금계산서 등)은 `merge_vendor`가 자동 승계 — 유실 없음.
4. **과거 내역**: 2026-06 이전 미수·미지급은 상계 후 기초원장으로 새로 관리하는 방침
   (회계 처리는 별도 승인 사이클 — 고객관리 반영과 독립).
5. 집계 시트·보조 열은 "사용자가 보고 싶어 하는 집계"로만 인지 (이행 대상 아님 —
   화면 KPI 요구사항으로 반영).
