  3. 묶음 — 프로필 설정에 따라 주문 1건 1파일, 또는 같은 날 주문을 한 파일(명단형 양식만)
  4. 원본 양식 복사 — 업체 양식 파일을 그대로 열어 서식 · 병합 · 수식 · 드롭다운 · 숨김 시트 · 로고 · 메모를 보존
  5. 채우기 3종 — 머리 칸(칸 1개에 값 1개) / 행 반복(품목별 또는 수령인 × 품목별, 모자라면 서식 · 수식 복사해 행 추가) / 품목 목록형(코드로 행을 찾아 수량만, 없는 품목은 행 추가)
  6. 자동 보정 — 행을 끼워 넣으면 아래 병합 · 합계 수식 범위 · 인쇄영역을 함께 옮김. 열 때 수식 다시 계산
  7. 점검 — 수량 · 단가 비었음, 업체 목록에 없는 품명 · 옵션, 수령인 배분 합계 ≠ 주문 수량
  8. 파일명 규칙 — 업체별 규칙 + 그날 업체별 순번(NO.1, NO.2 …)

업체 추가 방법 (지금 구조)

  1. 빈 양식 + 실제 발송본(품목 2개 이상)을 받음
  2. 개인정보를 비운 양식을 템플릿으로 저장 (.xls는 .xlsx로 변환)
  3. 프로필 1개 작성: 시트 이름, 칸 → 값, 행 시작 · 준비 행 · 꼬리 행, 묶음, 파일명
  4. 샘플 주문으로 생성 → 발송본과 칸 단위로 대조
  5. [가정] 항목을 업체 · 담당자에게 확인 후 확정

다음 단계에서는 이 프로필을 화면에서 칸을 눌러 연결하는 방식(앞서 이야기한 ‘양식 파일 + 칸 연결’)으로 옮겨 개발 없이 추가하게 합니다. 이번 4개 양식으로 보면 머리 칸 · 행 반복 · 품목 목록형 3가지로 모두 표현됩니다.

  2. 업로드하면서 파일명의 한글이 지워졌습니다. 원래 파일명 5개를 알려주세요 — 깨끗한나라 ‘2026-10-29_?_NO.1’, 해저식품 ‘260918_?_NO2’의 가운데 부분이 파일명 규칙입니다.

삼진어묵
