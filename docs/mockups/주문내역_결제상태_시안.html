주문내역 결제 상태 시안

2026-11-13 · 주문내역 목록의 "수금" 칸을 "결제" 한 칸(수단 꼬리표 + 단계 5개)으로 바꿉니다. 숫자와 이름은 예시입니다. 파란 칸이 바뀌는 부분입니다.

1. 단계 5개와 수단 꼬리표

표기언제누구 차례지금 표기
미결제결제 기록도 매칭도 없음영업지원 — 결제 안내미수금
카드일부 결제기록 + 매칭 금액이 주문 금액보다 적음영업지원 — 나머지 결제 안내미수금 또는 진행중
카드매칭 대기전액 기록됨, 매칭된 금액 없음회계 — 결제 확인 화면에서 대조미수금
카드일부 매칭전액 기록됨, 일부만 매칭됨회계 — 나머지 대조진행중
완료주문 금액 전액 매칭됨없음수금완료
수단 꼬리표 카드이체계산서선결제혼합 — 수단이 두 가지 이상이면 "혼합". 미결제 · 완료에는 꼬리표를 붙이지 않습니다.
기록이 덜 됐으면 "일부 결제"가 먼저입니다. 일부가 이미 매칭됐어도 영업지원이 나머지를 받아야 하므로 "일부 결제"로 둡니다.
기록 없이 매칭된 금액도 1차에 포함합니다. 입금 매칭 화면에서 바로 붙인 입금, 선결제 사용은 이미 매칭까지 끝난 것이라 1차 · 2차에 함께 들어갑니다. 전액이면 바로 "완료"입니다.
이때 수단은 매칭된 원본에서 정합니다 — 통장 입금 = 이체, 카드 매출 = 카드, 선결제 사용 = 선결제.

4. 함께 정할 것

#항목가안
1"확인"을 "매칭"으로 바꾸는 범위이 목록뿐 아니라 주문 상세의 기록 배지(확인 대기 → 매칭 대기, 결제 확인 → 매칭 완료)도 맞춘다. 메뉴 이름 "결제 확인"과 "확인 해제"는 그대로 둔다.
2미수금 칸 아래 "기록 N원"붙인다. 필요 없으면 뺌.
3주문 상세 머리의 수금 상태 표시목록과 같은 표기로 맞춘다.
4회계 쪽 ERP 주문내역이번에는 손대지 않는다(수금완료 · 진행중 · 미수금 유지).
