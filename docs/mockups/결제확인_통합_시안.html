2026-11-16 · 수금 · 정산 작업의 화면 4개를 "결제 확인" 한 화면의 탭 4개로 합칩니다. 숫자와 이름은 예시입니다. 파란 테두리가 새로 만들거나 바뀌는 부분입니다.

1. 메뉴와 탭

지금 메뉴정리 후누구 일내용
결제 확인결제 확인 › 매칭 대기회계지금 화면 그대로. 주문에 남긴 결제 기록을 원본과 대조해 확정.
입금 매칭결제 확인 › 기록 없는 입금회계결제 기록 없이 들어온 통장 입금 · 카드결제를 주문에 붙임. 자동 확정은 없앰(2번).
수금 대상결제 확인 › 결제 안내 대상영업지원아직 결제가 덜 된 주문 목록. 연락 기록을 남김(3번).
계산서 발행 대상결제 확인 › 계산서 확인영업지원 · 회계계산서를 발행했다고 기록했는데 홈택스에 없는 주문, 이체로 받았는데 증빙이 없는 주문(4번).

사이드바 "수금 · 정산 작업"에는 결제 확인 하나만 남습니다(매입 쪽 화면은 그대로). 옛 주소로 들어오면 해당 탭으로 넘겨 줍니다.
매출처별 미수 합계표(지금의 수금 대상)와 매출처별 현황판(지금의 계산서 발행 대상)은 없앱니다 — 같은 숫자가 회계의 미수금 관리와 매출처 관리에 있습니다.

5. 정해 주실 것

#항목가안
1탭 이름매칭 대기 · 기록 없는 입금 · 결제 안내 대상 · 계산서 확인
2매출처별 합계표 · 현황판을 없애도 되는지없앤다. 같은 숫자는 미수금 관리 · 매출처 관리에서 본다.
3연락 기록(1301)넣는다. 영업지원의 수금 독촉이 남는 곳이 지금 없음.
4계산서 탭의 성격"발행 대기 목록"이 아니라 위 세 가지 확인 목록으로 한다.
5추천 일괄 확정체크한 추천만 한 번에 확정할 수 있게 한다(확인 1회).
6결제 안내 대상의 권한보기 = 수금 · 정산 작업 조회, 연락 기록 = 주문 · 발주 수정 권한(영업지원).
