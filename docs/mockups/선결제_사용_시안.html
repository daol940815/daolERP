선결제 사용 시안 — 주문 결제에 선결제 잔액 일부를 쓰기

사용자 확인(2026-11-05): 선결제는 여러 주문에 나눠 쓰고, 품목을 선결제 처리하기보다 결제 금액 중 일부를 선결제에서 차감하는 경우가 많으며 (예: 20만 원 + 25만 원 주문 중 30만 원을 선결제에서), 영업지원팀이 처리합니다.
그래서 선결제 사용을 통장 · 카드처럼 결제 수단 하나로 다룹니다 — 주문 상세 결제 내역에서 "선결제 사용"으로 금액을 붙이면 그만큼 미수가 줄고, 매출처 선결제 잔액이 줄어듭니다.

전체 흐름

1. 선결제 받기주문서에 '선결제' 품목으로 저장 → 매출처 선결제 원장에 입금 자동 기록 (어제 반영)
→
2. 주문평소대로 주문 입력 (품목 20만 + 25만 = 45만). 주문처를 고르면 "선결제 잔액 N원" 안내
→
3. 선결제 사용주문 상세 › 결제 내역 › 선결제 사용 30만 → 원장 사용 기록 + 이 주문 수금 30만
→
4. 나머지남은 미수 15만은 통장 · 카드 수금 매칭으로 (기존 그대로)

D. 어떻게 저장되나 (참고)

선결제 사용 1건 = ① 선결제 원장에 사용(차감) 1행 (주문 연결) + ② 수금 매칭에 "선결제" 종류 1행 (같은 금액, 위 원장 행을 가리킴).
②가 있어 미수 계산(회계 표준 규칙)이 통장 · 카드와 똑같이 차감합니다 — 미수 규칙 자체는 고치지 않습니다. 해제하면 ① ②를 함께 지웁니다.
필요한 DB 변경: 마이그레이션 514 — 수금 매칭 종류에 '선결제' 추가 (지금은 통장 · 카드 · 현금만 허용). 회계 분개는 매칭 기록을 쓰지 않아 영향 없음.

F. 확인 부탁드릴 것

시안 확정 전에 정해주세요

  1. 사용 입력 위치 — 가안: 주문 상세 결제 내역에서만 (주문서는 잔액 안내). 주문서 저장 때 바로 넣는 칸도 원하시면 추가.
  2. 잔액 초과 사용 — 가안: 막음. (예전 회계 화면 차감 버튼은 경고만 하고 허용했음)
  3. 해제 권한 — 가안: 주문 수정 권한이 있는 영업지원팀 누구나 (본인 · 관리자 제한 없음). 해제 기록은 변경 이력에 남김.
  4. 선결제를 받은 주문의 입금 확인(선결제 주문인데 통장 입금이 들어왔는지) — 가안: 이번 범위 밖. 미수 정의를 바꾸는 일이라 회계 트랙과 따로 정함.
  5. 회계 화면의 기존 '선결제차감' 버튼(차감만 하고 미수는 안 줄임) — 가안: 회계 세션에 새 방식으로 통일하자고 공유.
