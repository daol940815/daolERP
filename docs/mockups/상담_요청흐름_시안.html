주문일

그 상담으로 만든 주문서의 주문일(취소 주문 제외). 전환 전에는 빈칸. 2건 이상이면 가장 이른 날 + "외 N", 마우스를 올리면 주문번호 목록. 상세 화면에도 상담일 오른쪽에 같은 값(읽기 전용, 누르면 주문으로 이동).

종결 · 발주 완료 (자동)

연결된 주문(취소 제외)의 품목이 모두 발주서에 들어가면 — 주문 목록의 '발주완료'와 같은 기준. 저장하지 않고 볼 때마다 계산하므로 주문을 고쳐 발주할 품목이 다시 생기면 '주문전환'으로 돌아갑니다.

종결 · 사유 (수동, 지금처럼)

주문 없이 끝난 상담(문의만, 고객 취소 등) — 지금처럼 사유를 골라 직접 종결 · 재개. 표시는 "종결 · {사유}". 상태 칩 '종결'은 두 가지를 함께 보여줍니다.

그 직원이 입력한 주문(취소 제외) 중 발주가 끝나지 않은 것 — 주문 목록의 미발주 · 부분발주. 3번 종결 기준과 같은 뜻("아직 일이 남은 주문").

함께 바뀌는 것 · 그대로인 것

  • 진행 이력은 새 표 하나(마이그레이션 711)에 쌓입니다 — 요청 · 넘김 · 재요청 · 취소 · 처리 불가. 주문 입력 · 완료 회신은 기존 기록(주문 · 515 회신)을 이어 붙여 보여줍니다. 711 적용 전 요청에는 이력이 "요청" 한 줄만.
  • 알림(PC 알림 포함): 넘김 → 새 진행자 · 요청자 / 재요청 → 새 진행자 · 이전 진행자 / 취소 → 진행자.
  • 요청 가능 조건(지점 · 담당자 마스터 연결), 요청받은 직원은 상담 수정 불가, 아침 재알림, 완료 회신 규칙은 그대로.
  • 요청자 = 처음 요청한 직원(상담 작성자 또는 관리자급). 넘겨도 요청자는 바뀌지 않아 끝까지 진행을 봅니다.
