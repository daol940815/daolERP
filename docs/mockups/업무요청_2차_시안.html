8결정해 주실 것

  1. 팀 빠른 선택 범위: 팀 4개(영업·영업지원·경영지원·아르바이트) + "전 직원" 버튼 — 전 직원 버튼도 둘지?
  2. 공동 방식에서 요청자의 조기 완료 확정: 전원 보고 전에도 요청자가 완료 확정 가능(시안 3) — 허용할지, 전원 보고 후에만 허용할지.
  3. 선착 방식에서 담당자 추가: 수락자가 나온 뒤에도 요청자가 담당자를 추가할 수 있게 둘지(추가하면 공동처럼 2명이 됨) — 단순하게 "선착은 추가 불가"로 둘 것을 권고.
  4. PC 알림 기본값: 허용 안내를 로그인 직후 1회 띄우고 종류 5개 중 "주문 수정 승인"만 기본 끔(시안 6) — 동의?
  5. 오늘 마감 아침 알림 시각: 09:00 1회 — 다른 시각이면 지정.
  6. 순서: 3·4(다수 담당자)와 ⑥ 2단계를 먼저 배포하고 ⑦ Web Push를 다음 묶음으로 — 동의? (한 번에 하면 1주, 나누면 3·4+⑥ 3일 → ⑦ 2일)
