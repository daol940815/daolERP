고객 쌍방향 추천 시안 (상담일지 · 주문서 공용)

지금은 업체 → 지점 → 담당자 한 방향으로만 고릅니다. 영업자는 지점명보다 고객 이름 · 핸드폰을 더 정확히 알고 있으므로, 어느 칸에서 시작하든 나머지를 채울 수 있게 합니다. 칸 배치는 지금과 같고, 담당자 · 핸드폰 칸이 검색 칸이 됩니다. 목록에서 고를 때만 채웁니다(시스템은 추천, 확정은 사용자). 업체 → 지점 → 담당자 순서로 고르는 기존 방식도 그대로 됩니다.

5. 동작 규칙

항목규칙
채우는 시점목록에서 고를 때만. 자동으로 덮어쓰지 않음. 고른 뒤 "되돌리기"로 이전 값 복원.
검색 시작이름 2글자 이상 · 번호 숫자 4개 이상. 결과 최대 20명.
검색 대상거래처 담당자 마스터(병합된 인물 제외). 현재 소속 → 이전 소속 순, 같은 순위는 최근 주문일 순.
지점을 먼저 고른 경우지금처럼 그 지점 담당자만 먼저, 없으면 "다른 지점에서 찾기"로 전체.
채우는 항목업체 · 지점 · 담당자 · 핸드폰 · 유선(116) · 다올 담당(주문 시 상담자). 이미 손으로 친 핸드폰 · 유선은 다를 때 안내만(116 규칙).
개인 고객 업체업체 '개인'은 지금의 개인 고객 검색(이름 · 전화번호) 그대로.
권한주문 그룹 조회 권한이면 검색 가능(아르바이트 포함, 읽기만). 신규 등록 차단 규칙은 그대로.
DB마이그레이션 없음. 검색 API 1개 추가(상담 · 주문 공용).
함께 정리할 것 (점검 결과 연계)
업체 목록에 지점 없는 업체 42곳이 남아 있습니다. 업체 칸 목록은 활성 지점이 1곳 이상인 업체 + 개인 고객 업체만 보이게 하면 '푸본헌대생명' 같은 고아 업체가 사라집니다(DB 변경 없음).
확인할 것 ① 담당자 · 핸드폰 칸을 검색 칸으로 쓰는 방식(별도 "고객 찾기" 칸 없이) ② 번호 전체가 맞을 때 한 줄 안내 + "이 고객으로 채우기" ③ 인사이동 시 현재 소속으로 바꾸고 되돌리기 제공 ④ 신규 등록 시 비슷한 이름 경고(막지 않고 묻기) ⑤ 업체 목록에서 지점 없는 업체 숨김을 함께 적용.
