확인해 주실 것

  1. 급여 기록 항목(귀속월·총액·지급일·구분·메모)으로 충분한지, 구분값(월급/상여/일당) 추가가 필요한지.
  2. 스케줄의 "영업 일정"을 위해 영업일지에 예정일을 추가해도 되는지(현재는 실행 기록만) — 영업팀이 계획을 적을 의향이 있는지가 관건.
  3. 아르바이트 등록 항목(시즌·일당·담당 직원)과 계정 ID 규칙(pt-이름), 급여 예정 = 일당 × 출근일수 산식.
  4. 직원 목록·상세를 인사·총무 첫 화면(직원 목록)으로 두고 권한 편집은 상세 안의 버튼으로 옮겨도 되는지(현재는 목록의 권한 버튼).
