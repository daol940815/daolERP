F. 확인 부탁드릴 것

시안 확정 전에 정해주세요

  1. 배송지 필수 여부 — 지점 · 샘플 품목이 있는데 주소가 비어 있으면?
    가안: 저장은 허용하고 주문 상세 · 발주서 작성 화면에 "배송지 미입력" 경고만 표시 (주문은 전화로 먼저 받고 주소는 나중에 받는 경우 고려). 필수로 막는 쪽도 가능.
  2. 자동 채움 기준 — "같은 주문처의 최근 배송지" (가안) vs "같은 담당자의 최근 배송지"
    한 지점에 담당자가 여럿이고 각자 다른 곳으로 받는다면 담당자 기준이 맞습니다.
  3. 지점 · 개별 혼재 주문 — 배송지를 지점 · 샘플 품목에만 쓰는 처리(가안)로 괜찮은지.
  4. 상담일지에도 같은 배송지 칸을 넣어 주문 전환 시 넘어오게 할지 (가안: 1단계는 주문서만, 상담일지는 다음에).
