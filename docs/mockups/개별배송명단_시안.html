개별 배송 명단 시안

개별 배송(수령인 다수) 상담에 표준 양식 엑셀로 명단을 올리면 수령인 행 데이터로 저장되고, 주문 전환 → 발주서 배송명단까지 같은 행이 따라갑니다. 지점·샘플은 기존 배송지 카드(1곳) 그대로. 매입처 자체 발주서 양식(대경사과 송장등록 등)은 예외 — 현행 유지.

상담 → 주문: 복사가 아니라 연결(주문 id 채움). 주문 → 발주서: 발주서의 품목 행에 연결된 수령인 행만 골라 시트 채움. 4페이즈: 같은 행에 송장번호 기록.
권한·보관 명단은 수령인 개인정보 — 열람은 주문 그룹 조회 권한, 엑셀·원본 다운로드는 누가 언제 받았는지 기록. 원본 파일은 Storage에 보관(원본 보존), 파싱 행은 테이블. 상담 저장 전에도 명단을 올릴 수 있게 하려면 상담을 먼저 저장해야 하므로, 명단 블록은 저장된 상담(수정 화면)에서 열립니다 — 신규 작성 중에는 "저장 후 명단 업로드" 안내.
