3. 주문서 전환 흐름

[주문서로 전환] 클릭 → 주문 입력 화면이 상담 내용으로 미리 채워진 채 열림 (업체·지점·담당자·품목·수량·가격·메모) → 빠진 필수값만 보완 (마스터 미등록 업체·담당자는 이 단계에서 등록 안내) → 주문 저장 → 상담일지 상태 '주문전환' + 주문번호 연결.
· 상담 1건에서 여러 주문 전환 가능 (분할 주문) · 전환 없이 종결 처리도 가능 · 상담만 하고 전환 안 된 건은 목록 '진행중' 필터로 추적
실물 시트와 달라진 점
· 판매합계·매입합계·마진율·배송비: 수기·수식 → 원가표 기준 자동 계산 (수정 가능)
· 업체/지점/담당자/품번: 자유 입력 → 마스터 자동완성 (상담 단계는 자유 입력 겸용 — 신규 고객 대비)
· 결제정보·패스워드: 평문 보관 → 암호화 저장 + 화면 마스킹 (사용자 확정)
· 최신품번 컬럼 제거 (사용자 확정 — 품번 검색이 항상 최신 마스터 참조)
· 상담 1건 = 문서 1건 + 품목 N행 (엑셀의 연속 행 방식을 구조화)
· 저장 시 업무일지(영업일지) 자동 기재 · 구분(주문/문의 등)과 전환 상태는 별도 관리 (사용자 확정)
