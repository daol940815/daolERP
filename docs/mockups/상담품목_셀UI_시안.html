상담 품목 — 셀 UI 개편 시안

엑셀처럼 칸이 하나하나 떨어진 셀 표, 모서리는 살짝 둥글게. 품목 · 판매 · 매입 · 결과를 색으로 묶어 어디를 보고 있는지 바로 알 수 있게 했습니다. 아래 표는 실제로 눌러서 고쳐 볼 수 있습니다(합계 · 마진이 바로 다시 계산됨).

1. 엑셀 같은 셀

칸 사이에 간격을 두고 칸마다 둥근 테두리(7px). 칸 자체가 입력 칸이라 안에 또 상자가 없습니다. 누른 칸은 진한 테두리로 표시. 숫자는 오른쪽 정렬, 글자 13px(지금 12px).

2. 묶음별 색

머리줄 위에 묶음 띠(품목 · 판매 · 매입 · 결과)를 두고, 판매는 파랑 · 매입은 주황 · 결과는 초록 테두리와 머리 색으로 구분. 지금처럼 비슷한 회색 칸이 이어지지 않습니다.

3. 입력 칸과 계산 칸 구분

사람이 넣는 칸은 흰 바탕 + 묶음 색 테두리, 자동 계산 칸(카톤 · 판매합계 · 매입합계 · 마진)은 묶음 색으로 칠하고 굵게 — 손댈 칸과 볼 칸이 한눈에 갈립니다.

4. 요약 막대

표 위 오른쪽에 판매합계 · 매입합계 · 마진을 같은 묶음 색 알약으로. 할인이 있으면 빨간 알약이 하나 더 붙습니다(지금은 표 아래 글줄).

지금과 무엇이 달라지나

지금
  • 모든 칸이 비슷한 회색 · 옅은 파랑 상자 — 판매인지 매입인지 머리줄을 다시 봐야 함
  • 칸 안에 입력 상자가 또 있어 선이 이중으로 보임
  • 합계 · 마진이 입력 칸과 같은 모양이라 고칠 칸으로 착각
  • 요약(예상 합계 · 매입 합계 · 마진)이 표 아래 글줄
개편
  • 칸 = 입력 상자 하나, 칸 사이 간격 4px, 둥근 모서리 — 엑셀 셀처럼
  • 품목 회색 · 판매 파랑 · 매입 주황 · 결과 초록 — 묶음 띠와 칸 테두리 색이 같음
  • 자동 계산 칸은 칠한 칸 + 굵은 글자, 입력 칸은 흰 칸
  • 상태 · 색상옵션 · 비고는 지금처럼 품목 아래 둘째 줄(옅은 칸), 품절 등 상태가 있으면 빨간 칸
  • 열 구성 · 순서 · 입력 규칙 · 단축키(↑↓ Tab Enter Esc)는 그대로 — 모양만 바뀜

함께 정할 것

  • 주문서(신규 주문 · 주문 상세)의 주문 상품 표도 같은 모양으로 바꿀지 — 같은 규칙의 표라 함께 바꾸면 화면 간 혼동이 줄어듭니다(권장).
  • 색 테마: 묶음 색(파랑 · 주황 · 초록)은 의미 색이라 테마와 무관하게 유지, 바탕 회색은 직원별 색 테마를 따릅니다. 글자 크기 설정(크게)에서도 칸 높이가 함께 커집니다.
