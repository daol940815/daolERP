계산서 매칭 키워드 (match_aliases · 기존)

계산서의 공급자 상호가 거래처명과 다를 때. 사업자번호가 있으면 거의 안 쓴다.

한국포장산업 ✕
통장 키워드 (bank_keywords · 신규)

통장 적요·보낸분/받는분에서 이 매입처를 찾는 표현. 다른 거래처와 겹치면 저장 시 경고(겹치면 자동 연결이 둘 다 건너뜀).

한국포장 ✕한국포장(주) ✕

학습: 통장 내역에서 거래처를 직접 고르면 "이 적요를 통장 키워드로 추가할까요?"를 묻는다(계정과목 키워드 학습과 같은 흐름). 계산서 결제 수동 매칭 때의 자동 학습도 여기로.

동작 규칙 · DB 변경
  • · 423 마이그레이션: vendors.bank_keywords TEXT[] 추가, 시작값은 기존 match_aliases 복사(지금 통장 매칭이 그걸로 돌고 있어 비우면 끊김). 이후 두 목록은 따로 간다. 원본 데이터 변경 없음.
  • · 통장 거래처 자동 매칭: 사업자번호 · 상호 · 통장 키워드만 본다(계산서 키워드 제외). 단 하나의 거래처에만 걸릴 때 연결 — 기존 규칙·짧은 이름 경계 규칙 유지.
  • · 대사 집계는 연결(vendor_id) 기준이지 확정·분개와 무관. 계정과목 미분류 거래도 들어온다.
  • · 제외: 계좌 간 이체쌍, 카드사 거래처의 카드대금 출금. 매출·매입 겸용 거래처는 출금만 매입 대사에 쓴다.
  • · "거래처 미연결 출금"(목록 KPI)은 대사 밖의 돈 — 키워드를 넣어 연결할수록 대사가 정확해진다. 클릭하면 통장 내역 화면에 거래처:없음 출금 필터로 연다.
  • · 매출처 허브도 같은 칸을 쓴다(통장 입금 ↔ 매출 계산서·ERP 수금 대사). 이번 범위는 매입처, 매출처는 다음 단계.
