주문 진행 요청 시안 — 상담은 내가, 주문은 다른 직원이

사용자 확정(2026-11-05): 담당자는 전 직원 중에서 · 한 상담에 한 명 · PC 알림까지 · 주문의 다올직원 = 실제로 입력한 사람, 상담자 = 요청한 사람(상담 작성자).
상담일지에 "주문 진행 담당"을 지정하면 그 직원에게 알림이 가고, 그 직원이 상담을 주문으로 전환하면 요청은 자동으로 완료됩니다.

전체 흐름

1. 요청영업자가 상담일지 작성 → "주문 진행 담당"에 김승현(아르바이트) 지정 → 저장
→
2. 알림김승현에게 사이드바 알림 + PC 알림 "주문 진행 요청 — 하나은행 일산지점 (옥광일)"
→
3. 전환김승현이 상담일지 "나에게 요청됨"에서 열고 "주문서로 전환" → 저장
→
4. 완료요청 자동 완료 → 옥광일에게 "주문 완료 D261105-012" 알림. 주문의 다올직원 김승현 · 상담자 옥광일

F. 확인 부탁드릴 것

시안 확정 전에 정해주세요

  1. 요청 위치 — 가안: 상담일지 작성 · 수정 화면 아래 "주문 진행 요청" 칸 + 목록 행에서도 "요청" 버튼(작성자만).
  2. 요청받은 직원의 수정 권한 — 가안: 상담 내용 수정 · 전환 모두 가능 (작성자와 같은 권한).
  3. 아르바이트 + 마스터 미연결 상담 — 가안: 요청 저장은 막고 "먼저 연결" 안내. (정규 직원에게는 안내만)
  4. 요청 후 오래 처리 안 된 건 — 가안: 요청 다음 날 아침 9시 PC 알림으로 한 번 더 알림(업무 요청 아침 알림과 같은 시간). 필요 없으면 뺌.
