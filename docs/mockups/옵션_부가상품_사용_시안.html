옵션(부가상품) 사용 안내

포장지·쇼핑백 등 부자재를 본 상품에 딸린 옵션 행으로 붙이는 기능 — 이미 운영에 반영되어 있습니다

1. 품목 마스터에서 부가상품 지정 → 2. 주문 입력에서 옵션 칩 클릭 → 3. 저장 — 옵션 행이 본 상품에 연결 → 상세·엑셀·발주서에 그대로 반영

1품목 마스터 — 어떤 상품이 옵션인지 지정

원가표 엑셀을 업로드하면 품번이 XX-01 대역(기타 부자재 페이지)인 상품은 자동으로 부가상품으로 표시됩니다 (VIP·선결제는 제외). 자동 판정이 틀린 경우 품목 마스터 화면에서 상품 편집을 열어 체크박스로 직접 바꿀 수 있습니다.

부가상품 품목 마스터 > 상품 편집 폼의 체크박스
현재 부가상품으로 잡혀 있는 예: 롯데포장지(소) · 롯데쇼핑백 · 고급쇼핑백 (매입처 요아럽 대역) — 목록 화면에서 부가상품 표시가 붙은 상품들입니다.

2주문 입력 — 본 상품을 고르면 옵션 칩이 나타남

본 상품의 품번을 선택하면 매입처가 자동으로 채워지고, 같은 매입처에 부가상품이 있으면 그 행 바로 아래에 보라색 옵션 추가 칩이 자동으로 나타납니다. 칩을 클릭하면 끝입니다.

품번품명구분매입처판매가갯수배송비합계
31-05 요아럽 명절 선물세트 5호 지점 요아럽 28,000 30 4,000 844,000 ✕
옵션 추가 (요아럽) + 롯데쇼핑백 (500) + 롯데포장지(소) (300) + 고급쇼핑백 (800) ← 클릭하면 아래 3단계처럼 옵션 행이 삽입됩니다

칩은 본 상품 행에만 나타나고, 옵션 행 밑으로는 다시 나타나지 않습니다. 매입처가 다른 상품에는 그 매입처의 부가상품 칩만 뜹니다 (부자재는 같은 매입처 상품에만 쓴다는 원칙).

3칩 클릭 후 — 옵션 행이 본 상품 바로 아래에 붙음

옵션 행은 └ 표시가 붙고 회색 배경으로 구분됩니다. 본 상품의 구분과 수량을 그대로 물려받아 가격·배송비가 자동 계산되고, 수량이 다르면 그 칸만 고치면 됩니다.

품번품명구분매입처판매가갯수배송비합계
31-05 요아럽 명절 선물세트 5호 지점 요아럽 28,000 30 4,000 844,000 ✕
└10-01 롯데쇼핑백 지점 요아럽 500 30 0 15,000 ✕

본 상품 행을 삭제하면 딸린 옵션 행도 함께 삭제됩니다. 옵션 행만 지우는 것은 옵션 행의 ✕로 가능합니다. 옵션을 여러 개 붙일 수도 있습니다 (쇼핑백 + 포장지 동시).

4저장 후 — 어디에 어떻게 보이나

주문 상세: 옵션 행에 └ 표시와 "N번 행의 옵션" 안내가 붙어 본 상품 아래 들여쓰기로 표시됩니다.
주문 목록 엑셀: 옵션 컬럼에 "N번 행 옵션"으로 출력되어 본 상품과의 관계가 남습니다.
발주서: 옵션도 같은 매입처 품목이므로 본 상품과 한 장의 발주서에 함께 담겨 발송됩니다.
수정: 주문 수정 화면에서도 같은 방식으로 동작합니다 (옵션 연결이 그대로 복원됨).
