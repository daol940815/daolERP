시안 — 개인 고객 자동 분리 (A안)

업체가 '개인'이면 지점명 없이 고객(인물)마다 매출처를 시스템이 자동으로 나눈다. 직원 입력은 업체 = 개인, 지점 = 공란, 담당자 = 주문자 그대로.

파란 점선 = 이번에 바뀌는 부분. 고객명은 예시가 아니라 현재 '개인'에 묶여 있는 실제 고객 10명이다(고객관리문서 2026-11-05판). 모임(심통회 · 서신회 · 한록회30기 · 풀향기)은 지금처럼 '개인' 아래 지점으로 둔다(사용자 결정) — 자동 분리 대상이 아니다.

규칙

  1. 업체에 "개인 고객 업체" 표시를 둔다(이름 '개인'에 하드코딩하지 않음) — 지금은 '개인' 한 곳.
  2. 그 업체의 주문 · 상담은 지점명과 상관없이 고객(인물)으로 매출처를 정한다. 같은 인물 = 같은 매출처, 다른 인물 = 다른 매출처.
  3. 매출처 이름은 "개인 {이름}" — 직함 · 존칭은 넣지 않는다(화면이 붙임). 동명이인만 전화번호 뒷 4자리.
  4. 이름을 고치거나 사람을 합치면 매출처 이름도 따라간다(옛 이름은 별칭으로 보존).
  5. 같은 사람이 회사 고객이기도 하면(예: 김득진 = 5군단 인사처 중령(진)) 인물은 하나, 매출처는 둘 — 개인 주문과 부대 주문이 섞이지 않는다.
  6. 매출처 등록 창에서 업체 '개인'을 고르면 지점명 대신 고객을 고르게 한다(손으로 "개인 홍길동"을 만들지 않게).
