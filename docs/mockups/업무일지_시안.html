동작 방식 요약
1. 기록은 전부 자동 — 상담일지·주문서 API가 저장 성공 직후 업무일지 테이블(erp_work_logs)에 한 줄을 남긴다. 기재 실패해도 원래 저장은 유지(영업일지 잠정 구현과 같은 방식).
2. 모든 줄은 원본 문서로 드릴다운 — "상담일지 보기 / 주문서 보기" 클릭 시 해당 상세 화면으로 이동.
3. 조회 권한 — 본인은 자기 것만, manager/admin은 우상단 셀렉트로 팀원 업무일지 열람.
4. 기존 잠정 구현 이관 — 상담 저장 시 영업일지(contact_activities)에 넣던 '상담' 활동 자동 기재는 폐지. 이미 쌓인 자동 기재분은 마이그레이션(700번대)에서 업무일지로 이동. 영업일지의 '상담' 유형 자체는 유지(방문상담 등 직접 기재용).
