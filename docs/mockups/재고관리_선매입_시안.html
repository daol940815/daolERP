시안 — 재고 관리: 선매입 재고 · 부자재 · 비품 (2026-11-23)
사용자 결정(2026-11-23): ① 선매입한 물건은 회사(사무실)로 들어온다 ② 재고 원가를 따로 싣는 안 ③ 비품 = 생필품(휴지 · 물티슈 · 커피 등, 매출과 무관한 소모품) + 장비 자산(PC 등). 쇼핑백 · 포장재는 비품이 아니라 부자재 ④ 기존에 샘플로 넣은 선매입 건의 기초재고 이관은 확인 후 결정(이번 범위 아님).
상품명 · 수량 · 금액은 모두 예시입니다.
시안과 함께 확인 부탁드리는 것 4가지 — 답이 없으면 각 항목의 "시안 기준"으로 구현합니다.
A. 선매입 주문의 매출처 — 시안 기준: 매출처 칸에 "자사 재고(다올커머스)"를 고르면 선매입 전용 주문이 됩니다. 고객 주문을 받으면서 일부만 더 사 두는 경우는 같은 주문에 행을 하나 더(선매입 입고) 넣습니다.
B. 재고 원가 계산 — 시안 기준: 먼저 들어온 입고분부터 나간 것으로 보고 그 입고 단가를 씁니다(선입선출). 두 입고분에 걸치면 원장에 두 줄로 나뉩니다.
C. 부자재 사용 기록 — 시안 기준: 쇼핑백 · 포장재는 주문마다 차감하지 않고 사용 기록 + 월말 실사로 관리합니다(주문 연결은 선택). 주문마다 붙여 원가에 넣고 싶으시면 알려주세요.
D. 비품 메뉴 위치 — 시안 기준: 비품은 매출과 무관하고 경영지원팀 업무라 인사 · 총무 영역의 "비품 관리"로 둡니다. 선매입 재고 · 부자재 · 샘플 재고는 영업 · 주문 영역의 "재고 관리"에 둡니다.

흐름 한눈에 숫자 두 칸이 각자 한 가지 뜻만 갖게 합니다

1선매입 (입고)

주문 입력에서 품목 행의 재고 칸 = 선매입 입고
발주서는 평소처럼 매입처로 나갑니다.
매입합계 = 매입액 (매입처에 줄 돈, 미지급금 · 대사에 그대로)
재고 원가 = 0 (아직 팔지 않음, 재고로 보관)
판매가 0 · 매출 0, 마진 집계에서 제외(손실로 보이지 않음)

2재고 관리 › 선매입 재고

입고분(주문 행)마다 남은 수량 · 단가가 자동으로 쌓입니다.
재고 = 입고 − 출고 ± 조정 (저장하지 않고 계산)
실사로 실제 수량을 확인하고, 차이는 조정 행으로 남깁니다.
재고 금액 = 남은 입고분 수량 × 각 입고 단가

3재고 출고 (판매 · 샘플 · 내부 사용)

품목 행의 재고 칸 = 재고 출고
사무실에서 직접 내보내므로 발주 대상에서 제외
매입합계 = 0 (매입처에 줄 돈 없음, 칸 잠금)
재고 원가 = 입고 단가 × 수량 (자동, 저장 후 불변)
마진 = 합계 − 매입합계 − 재고 원가

  • 재고 배정 표: 재고 출고 행이 어느 입고분(선매입 입고 행)에서 몇 개를 · 얼마에 가져갔는지(선입선출 결과). 원장 · 입고분별 남은 수량이 여기서 나옵니다.
  • 재고 조정 · 실사: 선매입 재고 · 부자재 공용(실사 수량, 그때 전산재고 사본, 사유, 입력 계정). 샘플 재고(800)와 같은 방식.
  • 부자재: 품목 + 입고 · 사용 기록(수량 · 단가 · 증빙 행 연결 선택). 비품: 소모품(남은 수량 · 부족 기준 · 구입 기록) + 장비 자산 대장(+ 이력). 비품은 인사 · 총무 권한.
  • 요아럽 샘플 재고(800)는 데이터를 옮기지 않고 같은 "재고 관리" 화면의 탭으로만 묶습니다(이관 위험 없음).
  • 마진을 계산하는 곳(주문 현황 · 상세 · 엑셀 · 품목 마진 · 매출처 분석 · 결제 미리보기 등 약 20곳)은 원가 = 매입합계 + 재고 원가로 한 함수에 모읍니다. 선매입 입고 행은 마진 집계에서 뺍니다.

구현 순서(안): 1차 주문 입력 재고 칸 + 선매입 재고 탭 + 원장 + 마진 보정 → 2차 확인 필요 탭 · 실사 → 3차 부자재 · 비품. 기존에 샘플로 넣은 선매입 건의 기초재고는 확인 후 별도 데이터 작업.
