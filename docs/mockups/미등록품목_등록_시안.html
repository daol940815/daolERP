진행 전 확인할 것

  1. A + C 둘 다 이 모양으로 괜찮을까요?
  2. 필수 칸: 품명 · 매입처 · 매입가 · 판매가(행 구분에 맞는 것) — 괜찮을까요?
  3. 한 번만 쓰는 상품(예: 맞춤 제작)도 미등록 목록에 계속 남습니다. 목록에서 "등록 안 함"으로 숨기는 기능이 필요할까요? 필요하면 숨김 기록용 마이그레이션(1000번)이 하나 생깁니다.
  4. 작업 범위: A는 주문서(500번대) · 상담일지(700번대) 트랙 화면의 품목 행에 표시 · 버튼 · 등록 창을 붙입니다. 두 화면이 같이 쓰는 부품(form-shared)에 한 번 만들어 양쪽에 연결하는 방식으로, 이 세션에서 함께 진행해도 될까요?
