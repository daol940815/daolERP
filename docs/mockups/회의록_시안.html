핵심: 오프라인 회의와 온라인 토론을 같은 "회의 1건"으로 다룬다. 둘 다 마지막에 결론(결정 사항) + 후속 조치가 남아 같은 모양의 회의록이 된다.
오프라인 = 회의가 끝난 뒤 기록으로 등록 (바로 "마감" 상태로 저장 가능) · 온라인 = 주제글을 올리고 의견 마감일까지 댓글로 토론 → 주최자가 결론을 적고 마감.
미결(사용자 확인 대기): 공개 범위(추천: 전원 공개 + "참석자만 보기" 체크) · 첨부 1차 포함(추천: 예) · 아르바이트 참석 허용(추천: 아니오).

1회의록 목록

KPI 카드(클릭 = 필터) + 통합 검색 + 칩 필터 + 표. 상태는 데이터에서 자동 판정: 의견 마감일 전 = 진행 중, 마감일 지났는데 결론 없음 = 결론 대기, 결론 저장 = 마감. 빨간 숫자 = 내가 아직 읽지 않은 새 댓글 수. 기간 필터 표준(PeriodPresets) 적용, 기본 = 당년.

알림 (알림 센터 + PC 알림, 기존 업무 요청과 같은 경로)

  1. 참석자로 지정됨 → "OOO님이 회의에 초대했습니다"
  2. 내가 주최 · 참석한 회의에 새 댓글 · 내 댓글에 답글
  3. 의견 마감 하루 전 (진행 중 토론, 아직 댓글 안 단 참석자에게만)
  4. 마감 · 결론 확정 → 참석자 전원
  5. 주최자: 마감일이 지났는데 결론이 없을 때 "결론 대기"

권한 · 테이블 (1100_meetings.sql)

  1. 메뉴: 내 업무 › 회의록 (전원 조회 · 작성, API /api/meetings = my 그룹)
  2. 수정 · 마감 · 결론 수정: 주최자 + 마스터 계정 / 댓글 수정 · 삭제: 본인
  3. meetings · meeting_participants · meeting_comments · meeting_actions · meeting_attachments · meeting_events(수정 이력)
  4. 첨부는 Supabase Storage 비공개 버킷(발주서 첨부와 같은 방식), 내려받기는 서명 링크
  5. 회의 작성 · 댓글 · 마감은 업무일지에 자동 기재 (업무 요청과 같은 방식)
