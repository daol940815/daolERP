시안 — 매출처 하위 조직 (지점 › 팀 › 하위 팀)

2026-11-20 영업팀 의견: 은행을 지점 단위로만 관리해 하위 조직(본점 부서 › 팀, 원큐 › 자동차금융팀 등)을 다룰 수 없다. 예시는 하나은행 원큐(1Q) — 화면의 숫자와 경로(본점 › 채널전략부 › 원큐, 위치 방배금융센터)는 설명용 가정이고, 실제 소속은 보내 드린 엑셀로 확인한다.

핵심 — 팀도 지금처럼 매출처 하나다(주문 · 상담 · 담당자가 붙는 곳). 다만 매출처마다 상위 조직을 하나 지정할 수 있게 해 트리(조직도)를 만든다. 상위 조직과 별개로 위치(소재 지점)를 둘 수 있다 — 영남영업그룹팀은 원큐 소속이지만 서면역금융센터에 있다.
청구처와는 다른 개념 — 청구처(계산서 발행 법인, 탭 "소속 부서")는 돈의 흐름, 상위 조직은 조직도. 둘 다 따로 둔다.

매출처 상세

  • 경로(맨 위): 업체 › 상위 조직들 › 이 조직. 누르면 그 조직 상세로.
  • 위치 배지: 상위 조직과 다른 곳에 앉아 있을 때만(영남영업그룹팀 = 서면역금융센터). 방문 · 배송 기본 주소에 쓸 수 있다.
  • 집계 범위: "이 조직만" / "하위 포함". 하위 포함이면 매출 · 미수 · 주문 · 담당자를 하위 조직까지 더한다(숫자는 각 하위 조직 화면으로 드릴다운).
  • 하위 조직 탭: 바로 아래만이 아니라 전체 트리. 행을 누르면 그 조직 상세. "하위 조직 추가"는 등록 창에 상위 조직을 미리 채워 연다.
  • 주문 · 계산서 · 담당자 배정은 지금처럼 가장 아래 조직에 붙는다 — 팀 주문은 팀에, 원큐 공용 주문은 원큐에.
  • 기존 "소속 부서" 탭(청구처 법인 → 계산서를 대신 받는 부서)은 그대로 둔다 — 이름이 비슷해 헷갈리지 않게 새 탭은 "하위 조직".

상위 조직 지정

  • 매출처 상세의 "상위 조직 · 위치 변경", 등록 창의 "상위 조직(선택)" 칸에서 지정한다.
  • 후보는 같은 업체의 매출처만. 검색 결과마다 경로를 보여 줘 같은 이름(예: 본점 자동차금융부 vs 원큐 자동차금융팀)을 구분한다.
  • 순환 금지(자기 하위를 상위로 못 고름), 깊이는 최대 5단계(업체 아래).
  • 상위 조직을 바꿔도 주문 · 계산서 · 담당자는 그대로 이 조직에 남는다(집계 경로만 바뀜). 변경 이력을 남긴다(누가 · 언제 · 전 → 후).
  • 하위 조직을 새로 등록할 때 청구처는 상위 조직의 청구처를 기본값으로 제안(확정은 사람).

주문 · 상담 입력

  • 지점 칸 검색 결과 줄마다 경로를 작게 보여 준다 — 같은 이름의 팀을 헷갈리지 않게.
  • 고른 뒤 저장되는 주문의 지점 표기는 지금처럼 그 매출처 이름(원본 보존). 경로는 화면 표시용으로만 붙는다.
  • 입력 방식(업체 → 지점 검색)은 바뀌지 않는다. 지점이 늘어도 키워드로 1~3개만 뜨는 것은 11-20 실측과 같다.

데이터 (마이그레이션 120 — 100번대)

  • vendors.parent_vendor_id 상위 조직(같은 업체의 매출처, 비우면 업체 바로 아래) · vendors.location_vendor_id 위치(소재 지점, 선택).
  • 순환 · 자기 참조 금지 트리거, 깊이 5 제한. 병합 시 하위 조직 · 위치를 남는 쪽으로 옮기는 트리거(청구처 114와 같은 방식), 119 병합 기록 · 취소에 포함.
  • 변경 이력 표 vendor_parent_changes(전 → 후 · 누가 · 언제). 원본(주문 · 계산서)은 손대지 않는다 — 연결 정보만 추가.
  • 집계는 저장하지 않고 화면에서 트리를 따라 더한다(하위 포함 합계 = 각 조직 숫자의 합, 드릴다운 가능).

정해 주실 것

  1. 팀 이름 규칙 — (가) 지금처럼 '하나은행 자동차금융팀'으로 두고 경로로 구분 / (나) 상위 단위를 이름에 넣어 '하나은행 원큐 자동차금융팀'. 권고 (나): 엑셀 · 계산서 · 주문 표기처럼 경로가 안 보이는 곳에서도 구분된다.
  2. 본점 노드 — 본점 부서(채널전략부 · 영업지원부 등 46곳)를 묶는 '하나은행 본점' 매출처를 새로 만들지. 권고: 만든다(주문은 받지 않는 묶음용). 청구처 법인 '주식회사 하나은행'과는 별개.
  3. 위치(소재 지점) 칸을 둘지 — 권고: 둔다(영남영업그룹팀처럼 소속과 자리가 다른 경우).
  4. 집계 기본값 — 상세 화면을 열었을 때 "이 조직만" / "하위 포함". 권고: 하위가 있으면 "하위 포함".
  5. 첫 적용 범위 — 하나은행 원큐 계열 · 본점 부서부터(보내 드린 엑셀의 '상위 조직(제안)' 칸 → 그대로 반영), 다른 은행은 실무자가 화면에서.
