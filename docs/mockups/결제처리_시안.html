4. 정해 주실 것

#항목가안
1현금 수단을 둘지둔다. 실제로 안 쓰면 뺌.
2계산서 발행 기록의 금액주문 금액이 기본값, 고칠 수 있음. 홈택스 계산서가 올라오면 자동 연결하고 금액이 다르면 불일치로 표시.
3확인 대기가 며칠 넘으면 알릴지원본 최신일 기준 3일. 카드 · 이체만. 계산서 발행은 입금 예정일이 지난 뒤부터.
4확인 해제 권한결제 확인 화면 수정 권한자. 해제 사유 필수, 이력 기록.
5결제 확인 화면의 위치영업 · 주문 › 수금 · 정산 작업 그룹 맨 위. 기존 3화면 정리는 따로 결정.
