5. 걸러내지 않는 경우

구분 미기재 기록(1304 이전 18건) · 결제 기록이 없는 주문 — 지금처럼 전부 보여 줍니다.
한 주문에 과세 기록과 면세 기록이 둘 다 있는 경우 — 계산서 연결 창에서 걸러낼 기준이 없으므로 전부 보여 줍니다(머리에 "과세 · 면세 기록 모두 있음" 표시).
연결 창에서 주문을 여러 건 고른 경우 — 고른 주문들의 구분이 모두 같을 때만 걸러냅니다.
회계 › 계산서 내역에서 계산서 기준으로 연 연결 창 — 반대 방향입니다. 과세 계산서를 기준으로 열면, 면세로 기록한 주문이 같은 방식으로 접힙니다.
계좌이체 기록 · 통장 입금 — 구분이 없으므로 해당 없습니다.
