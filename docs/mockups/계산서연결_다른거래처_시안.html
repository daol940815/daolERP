3. 연결할 때 청구처 지정을 물어봄

다른 거래처 명의 계산서를 연결하면 한 번 묻습니다. 청구처로 지정하면 다음부터는 추천 조합에 바로 뜹니다.

계산서의 거래처가 다릅니다
주문은 하나은행 광운대출장소, 계산서는 하나은행 석계역지점 명의입니다.
광운대출장소의 계산서가 앞으로도 석계역지점 명의로 발행된다면 청구처로 지정하세요. 다음부터 이 창에 석계역지점 계산서가 함께 나오고 자동으로 추천됩니다.
두 매출처는 합쳐지지 않습니다. 주문 · 고객 관리는 출장소 단위 그대로입니다.
취소이번만 연결연결하고 청구처로 지정
묻지 않는 경우
· 이미 청구처가 지정된 매출처 — 다른 곳 명의면 "이번만 연결"만 나옵니다(청구처는 하나만 지정됨).
· 거래처가 없는 계산서 — 연결만 합니다.
· 청구처 지정 권한(거래처 관리 수정)이 없는 직원 — "이번만 연결"만 나옵니다.
바뀌지 않는 것
· 계산서 원본과 계산서에 연결된 거래처는 그대로입니다.
· 매출처 관리 › 청구처 지정 화면에서 언제든 해제할 수 있습니다.

4. 정해 주실 것

#항목가안
1후보로 알려 줄 범위전체 매출 계산서에서 금액 · 날짜가 맞는 것(은행이 달라도 표시). 후보가 하나뿐일 때만 바로 연결 버튼.
2청구처 지정 질문다른 거래처 계산서를 연결할 때마다 한 번. "이번만 연결"도 가능.
3적용 화면계산서 확인 탭과 매출처 상세의 연결 창 모두(같은 창을 씀).
43단 구조(출장소 → 지점 → 본점)지금처럼 한 단계만. 실제로 나오면 그때 "직접 찾기 → 이번만 연결"로 처리하고 구조를 다시 봄.
