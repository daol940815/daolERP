4. 경우별 동작

사람이 한 일자동으로 일어나는 일풀 때
계산서에 입금을 붙임회계 · 계산서 내역그 계산서에 연결된 주문의 수금으로 넘김 → 주문 미수 감소 · 결제 기록이 있으면 매칭 완료계산서에서 입금을 풀면 주문 수금도 함께 풀림

주문과 계산서가 연결돼 있지 않음없음 — 지금과 같음—
사람이 붙인 연결은 건드리지 않습니다. 자동으로 넘어온 것만 만들고 지웁니다. 자동으로 넘어온 것이 다시 반대쪽으로 넘어가지는 않습니다(되돌이 없음).
넘치지 않게: 주문 미수, 계산서 남은 금액, 입금 잔액 중 가장 작은 값까지만 넘깁니다. 주문 여러 건 · 계산서 여러 장이면 날짜 순으로 채웁니다.
