원래 시안과 달라진 점
· 검사 상태 컬럼 제외 — 기존 화면의 검사상태 정의가 아직 미확인(미답 3건 중 하나). 정의 확인되면 추가.
· 배송 컬럼 제외 — 배송 데이터는 3단계(배송 관리 통합)에서 생김. 그때 지연 경고와 함께 추가.
· 출처 컬럼·칩 추가 — 병행 운용 중이라 직접입력/업로드 구분이 필요. KPI 4번째 칸도 배송 지연 → 직접입력 건수로 교체.
· 행내 펼치기에 옵션(└)·구분 배지·배송비 표시 — 2단계 데이터 구조 반영.
· 마진은 admin/manager에게만 표시 (sales에게는 숨김) — 원가 노출 방지. (확인 요망)
· 검색은 상품명·품번까지 포함(품목 테이블 조인) · 기본 50건 페이지네이션 · 행 클릭=상세, 상품 N=행내 펼치기.
