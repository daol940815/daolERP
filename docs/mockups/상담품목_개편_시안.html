주문서 전환 시 배송비 행 처리 (확정 필요)
상담에서는 배송비가 눈에 보이는 행이지만, 주문 데이터에는 배송비 컬럼이 품목별로 존재하고 허브·회계 하류가 그 구조를 소비한다. 그래서 전환 시 배송비 행은 본 상품 행의 배송비 컬럼으로 합산되어 접힌다 (카톤단위 12,000 + 카톤외 4,000 → 본 상품 배송비 16,000). 주문 폼에서는 지금처럼 배송비 컬럼으로 보이고, 하류 집계는 무변경.
상태·색상옵션은 주문 품목 메모로 합쳐 넘긴다 (추후 발주서 개편 시 비고/메모/옵션 항목으로 매핑 변경 예정 — 사용자 예고).
동작 요약
1. 배송비 칩은 본 상품에 원가표 배송비 정보가 있으면 금액 자동 계산 (카톤단위: 수량÷카톤단위 올림 × 카톤배송비), 없으면 0원으로 추가 후 직접 입력.
2. 배송비 행은 품번 검색 없이 이름 고정, 금액(판매가)과 수량만 수정. 마진 계산에서 비용으로 반영.
3. 카톤단위 열은 원가표에서 자동 표시(읽기 전용). 부가상품·배송비 행은 "-".
4. 상태·색상옵션 입력줄은 본 상품 행 아래에만 표시 (옵션·배송비 행에는 없음).
