동작 규칙 요약
· 발주 단위: 주문 1건 안에서 매입처별 발주서 1장 (분할 발주 가능 — 품목 선택)
· 품목 단위 발주 추적: 발주된 품목은 재발주 불가, 발주 취소 시 미발주 복귀. 발주 후 주문이 수정되면 해당 품목은 미발주로 복귀 + 경고 표시(재발주 검토)
· 발주번호 POyymmdd-## 자동 발번 · 발송 성공/실패/수동이 이력에 남고 실패 건 재발송
· 매입처 이메일: 원가표에서 112곳 적재(마이그레이션 508), 미등록은 발송 화면에서 입력 → vendors 저장(매입처 허브와 공유)
· 자체 양식 매입처(vendors 표시): 1차 자사 양식 참고용 + 수동 발송 기록, 2차에 템플릿 재현
· 발주서 엑셀: 자사 양식 실물 수령 전까지 표준 임시 양식(품번·품명·구분·수량·매입단가·합계·비고 + 배송 참고)
