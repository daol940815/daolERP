v1 대비 달라진 점 (개념 정정)
· 발주의 단위: 여러 주문을 매입처별로 모아 일괄 발주 (v1) → 주문 1건 안에서 매입처별 발주서 작성·발송 (v2)
· 핵심 화면: 별도 발주 대기 화면 → 주문 상세의 발주 섹션 (주문내역의 하위 작업)
· 주문 현황 목록에 발주 상태 배지·필터 (미발주/부분/완료 — 품목 발주 여부로 자동 판정, direct만)
· 사이드바 '발주서' 메뉴는 발주 이력 조회로 축소 (주문번호 클릭 → 해당 주문 상세)
유지되는 규칙 — 품목 단위 발주 추적(중복 방지·분할 발주), 발주 취소 시 미발주 복귀, 배송 참고(주문 메모+상담일지) 자동, 네이버 SMTP + 백업 CC + 발송 이력, 자체 양식 매입처는 참고용 생성+수동 발송 기록, 이메일 미등록 시 그 자리 등록(vendors.email)
