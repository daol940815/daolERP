동작 규칙
· 발주 대상: direct 주문의 취소 아닌 품목 중 아직 발주서에 안 담긴 것 (품목 단위 추적 — 같은 품목 중복 발주 방지, 분할 발주 가능)
· 발주서 생성 시 발주번호(POyymmdd-##) 발번 + 품목 잠금. 발주서 삭제(취소) 시 품목은 대기로 복귀
· 배송 참고 컬럼: 주문 메모 + 연결된 상담일지의 배송요청일·인사장·명단수단 표시 (consultation_id 조인)
· 메일: 네이버 SMTP, 백업 CC 자동 포함, 발송 성공·실패가 이력에 남고 실패 건은 재발송
· 자체 양식 매입처: vendors에 플래그 — 1차는 자사 양식 참고용 생성 + 수동 발송 기록, 2차에서 빈도 높은 곳부터 템플릿 재현
· 이메일 미등록 매입처는 그 자리에서 등록 (vendors.email 저장 — 매입처 허브와 공유)
· 발주서 엑셀 양식은 실물 수령 후 재현 — 그 전까지는 표준 임시 양식(품번·품명·구분·수량·매입단가·합계·비고)으로 시안 검증
