"조회"는 화면은 보이되 입력·확정 버튼이 숨는 상태. 지금의 role 3단계(sales/manager/admin)는 이 표로 대체되며, admin은 "모든 권한 보유"로 남긴다(ERP 총괄 계정).

검토해 주실 것

  1. 그룹 이름 5+5개가 실무 말과 맞는지 (예: "수금·정산 작업" vs "수금·계산서", "경영지원 모드" vs "관리 모드").
  2. 통합 후보 7건 — 각각 합칠지, 지금처럼 따로 둘지. 합치면 화면 작업이 생기므로 1차(메뉴 이동·개명만)와 2차(통합)로 나눌 수 있다.
  3. "내 고객" 신규 화면 — 만들지, 매출처 허브를 그대로 워크스페이스에 노출하고 본인 담당 필터만 기본으로 켤지(후자가 빠름).
  4. 권한 표의 O/조회/— 가 실제와 다른 칸. 특히 경영지원팀의 payables.work(매입처 결제 확인)와 대표의 approve.
  5. 모드 선택 화면(/portal) 폐지 — 권한자에게만 모드 전환 링크를 보여주면 선택 화면 없이 로그인 → 워크스페이스로 바로 갈 수 있다.
