3. 함께 맞추는 것

조건 중첩칩을 몇 개든 쌓을 수 있고 모두 "그리고"로 묶습니다. 같은 항목도 여러 번 가능(예: 품명 포함 "타올" 그리고 품명 포함 안 함 "세트").
필터 유지새 필터 · 금액대 칩도 주소에 적어, 다른 화면에 다녀오거나 새로고침해도 유지(2026-11-11 필터 유지와 같은 규칙). 메뉴 클릭 = 초기화.
엑셀 다운로드화면에 걸린 필터 · 금액대 그대로 원가표를 받습니다(품번순 고정은 그대로). 걸러내는 규칙은 화면 · 다운로드가 한 파일을 같이 씁니다.
속도품목 2,300여 건을 이미 한 번에 받아 화면에서 거르므로 서버 조회는 늘지 않습니다.

진행 전 확인할 것

  1. 금액대 칩 기준: 기본을 지점판매가로 두고 선택 상자로 개별판매가 · 매입가로 바꿀 수 있게 할까요? (기준 하나만 고정해도 됩니다)
  2. 금액대 구간: 1천원 미만 / 1천~5천 / 5천~1만 / 1만~3만 / 3만~5만 / 5만~10만 / 10만 이상 — 이 구간으로 괜찮을까요? 실제 품목 가격 분포에 맞게 바꾸고 싶으면 알려 주세요. (경계값은 아래 구간에 포함: 5,000원은 "5천~1만")
  3. 금액대 칩 여러 개: 여러 개를 켜면 "또는"(그중 하나)로 묶는 안입니다. 한 번에 하나만 고르게 할까요?
  4. 조건 중첩 방식: 모두 "그리고"로만 묶는 안입니다. "또는" 묶음(예: 매입처 A 또는 B)까지 필요할까요? 필요하면 같은 항목 칩끼리만 "또는"으로 묶는 방식을 제안합니다.
