동작 규칙
  • · 기간 줄(프리셋 칩 + 날짜 from~to + 조회)은 서버 조회 조건, 검색 줄(+ 필터 + 검색창)과 빠른 조건은 불러온 행에 즉시 적용 — 조회 버튼을 안 눌러도 걸러진다
  • · + 필터 버튼은 검색창 왼쪽에 고정. 드롭다운은 버튼 아래 왼쪽 정렬로 열린다
  • · 위 요약(건수·입금·출금·미검토)은 걸러진 행 기준. "조건 일치 N건 / 기간 내 M건"으로 둘 다 보인다
  • · 전체 선택·추천 수락·선택 확정은 걸러진 행만 대상 (지금과 같음)
  • · 일치한 검색어는 적요에서 노란 표시
  • · 필터는 + 필터 드롭다운으로 설정(항목 선택 → 값 입력 → 추가). 검색창 단축 입력은 같은 칩을 만드는 보조 수단
  • · 기존 상태·출처 드롭다운은 필터 항목으로 통합. 열 머리글 필터는 남기되 입금액·출금액·잔액은 숫자 필터로 교체
  • · 빠른 조건 칩은 자주 쓰는 필터를 한 번에 거는 단축키 — 걸리면 적용 중 칩에도 나타난다
  • · 검색어·필터는 주소에 남아(?q=…) 새로 고침·링크 공유에도 유지
  • · 파서는 주문 현황과 같은 부품(lib)으로 — 지정어만 화면별로 다름
