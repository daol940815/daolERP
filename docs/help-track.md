## 총괄 제안 (2026-11-03)
- **별도 사용서(PDF·문서)는 권하지 않음** — 화면이 자주 바뀌어 한 달이면 틀린 내용이 된다. 도움말은 코드 옆(레지스트리)에 두고
  화면을 고치는 세션이 같이 고친다.
- 한 묶음: ① 화면별 도움말 패널(이 화면은 / 누가·언제 / 순서 / 자주 막히는 것) ② 기능 검색(업무 말·동의어, Ctrl K + 사이드바 검색창)
  ③ "이 화면에 대해 질문하기" → 업무 요청 자동 생성 ④ 첫 로그인 안내(권한 맞춤 3~5단계) + 권한·빈 화면·오류 메시지가 "다음 행동"을 말하기.
- AI 도우미는 지금 아님(도움말 내용이 쌓인 뒤 2단계). 직원 편집 위키도 두지 않음(틀린 내용 누적) — 질문 → 총괄 반영 경로로 통일.
- 내용 1차 범위: 영업지원팀이 매일 쓰는 화면 10개(신규 주문·주문 현황 / 품목 관리 / 상담일지 / 발주서 / 업무 요청 / 출근·근태·휴가 /
  샘플 재고 / 매출처 관리·내 고객 / 내 정보·알림 설정 / 수금 대상·입금 매칭·계산서 발행 대상). 회계 화면은 2차.
