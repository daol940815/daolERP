# 요아럽 샘플 재고 트랙 — 인수인계 문서

담당: **별도 세션 (샘플 재고 트랙)** — 총괄 세션에서 설계·드라이런 후 분리 (2026-08-18).
마이그레이션 번호: **800번대** (첫 파일 800부터. 이전에 예약했던 108은 사용하지 않음).
최종 갱신: 2026-08-18

## 배경

- 요아럽은 사장님의 다른 법인(서류상 대표는 타인)인 매입처. 제품을 다올커머스 사무실에
  들여와 영업 샘플·선물 증정용으로 소진하며, 입출고·재고를 엑셀로 관리해 왔다.
- 이를 ERP 기능으로 편입. 원본데이터 철학 적용: 입출고 원장이 원본, 재고·집계는 파생 계산.

## 확정 사항 (2026-08-18, 사용자 결정)

1. **두 출고 흐름은 별개**로 관리한다.
   - 요아럽 창고 출고 샘플: 기존 ERP 주문내역에 이미 기재됨(`erp_order_items.order_kind='샘플'`,
     요아럽 품목 291행 확인). 대부분 영업용. **재고 관리 대상 아님.**
   - 다올커머스 사무실 출고 샘플: 엑셀 원장으로 관리해 온 것. 영업용·선물용 혼재.
     **사무실 입출고만 재고 관리 대상.**
2. **샘플 비용 집계는 두 흐름을 통합**해서 본다 (창고 + 사무실).
3. **과거 엑셀 원장은 전체 이관**한다 (기초재고 방식이 아니라 전 이력).
4. **용도 구분 필드 추가** (영업샘플 / 선물증정).
5. 품목은 별도 테이블을 만들지 않고 **품목 마스터(erp_products) 참조** (요아럽 품목 66종 등록됨).
6. 재고 산식: 전산재고 = 입고 누계 − 출고 누계 (저장하지 않고 계산). 실재고는 현장 실사 기록.

## 저장 구조 (안 — 마이그레이션 108)

- **사무실 입출고 원장 `erp_sample_moves`** (신규): 사무실 흐름 전용. 테이블 자체가
  "사무실" 위치 표식이므로 주문내역에 출고 위치 컬럼을 추가하지 않는다.
  - move_date / move_type(`in`·`out`·`adjust`) / product_id(FK erp_products, NULL 허용)
  - item_name_raw(엑셀 원본 품명 보존) / quantity / unit_cost·total_cost(기록 시점 매입가 스냅샷)
  - purpose(`sales`·`gift`, 출고만) / dest_name(출고처 원본 텍스트) / staff_name(담당자 원본 텍스트)
  - employee_id(FK, 선택 연결) / contact_id(FK, 선택 연결 — 영업일지 연계 고리) / note / source(`excel`·`manual`)
- **재고 실사 `erp_sample_stocktakes`** (신규): take_date / product_id / counted_qty /
  computed_qty(실사 시점 전산재고 스냅샷) / note. 오차 해소는 `adjust` 원장 행으로 기록.
- **erp_products.is_sample_stock** boolean 플래그: 재고 화면 대상 품목 지정.
- 창고 출고분은 기존 주문내역 샘플 행을 그대로 사용(무수정). 비용 집계 화면에서
  두 소스를 합산. 창고 행은 매입가·매입합계가 이미 기재됨(918행 중 913행) — 기록값 사용.

설계 근거: 사무실 출고(출고처 대부분 비거래처 자유 텍스트, 629종)를 주문 헤더로 강제
생성하는 것보다 전용 원장이 자연스럽다. "같이 관리"는 통합 집계 화면에서 충족한다.

## 이관 드라이런 결과 (2026-08-18)

- 엑셀 상세내역 실데이터 **2,087행** (입고 239행·7,170개 / 출고 1,848행·5,942개),
  기간 2025-03-07 ~ 2026-08-18. 입고 매입액 합 33,406,200원 / 출고 매입비 합 29,963,250원.
- 품명 매칭(정규화 + 어순 무시 + 별칭 3건): **2,031행 / 2,087행 = 97.3%**.
  - 정규화 규칙: 전각 ＆, 괄호·용량(ml) 제거, 앰버/엠버, 클렌저/클렌져, 시트러시유주/유즈,
    '케어' 유무, 어순(디퓨저 향명) 차이 흡수.
  - 별칭 확정 필요 3건: 솝＆바디 세트→바이탈라이징 솝&바디세트 /
    핸드크림 3P 공용(아이보리)→…종이케이스(아이보리) / 고급쇼핑백→고급쇼핑백(마스터 2종 중 대표).
- **검증: 원장 계산 전산재고가 엑셀 집계 시트와 전 품목 일치. 실사(2026-08-18, 김승현) 오차 전부 0.**
- 미매칭 56행 = **마스터 미등록 품목** (등록 필요):
  - 요아럽 디퓨저 리드스틱 8개입 (25행, 재고 75)
  - 요아럽 디퓨저 스위피자스민 240ml (16행, 재고 17) — 마스터엔 향 5종만 있고 스위피자스민 없음
  - 내츄럴 마일드 선크림 1P·3P (13행) — '요아럽 마일드 선크림 1P·3P'(2행)와 동일품 추정:
    양쪽 재고가 정확히 상쇄(+4/−4, +10/−10) → 표기 변형으로 판단, 통합 별칭 처리 예정
  - 롯데 오리지널 쇼핑백 — 엑셀 집계는 '롯데 쇼핑백'(205)과 별도 품목(197)으로 구분.
    마스터엔 롯데쇼핑백 1종만 있음 → 별도 등록 여부 결정 필요
- 담당자 17종 중 직원 마스터 일치 8명. 미일치 8명(김대희 39행 등 총 83행)은 퇴사자 추정 —
  staff_name 원본 보존 + employee_id 선택 연결로 처리(주문내역 staff_name 패턴과 동일).
- '3P 분리' 출고 11행: 3P 세트를 낱개로 쪼개는 재포장 기록. 케이스 재고 −2 발생 —
  이관 시 그대로 보존하고 실사 조정으로 정리.
