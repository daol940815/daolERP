## 검토 결과 (Claude, 2026-11-23)

- `erp_order_items.purchase_total`(매입합계)은 매입처 대사 · 미지급금 · 매입 사이클이 "매입처에 줄 돈"으로 읽는다
  (`lib/vendor-reconciliation.ts`, `lib/vendor-ledger.ts`, `lib/erp-reports.ts`, `lib/purchase-cycle-status.ts`).
  → 출고 행 매입가 0은 이쪽 숫자를 정확히 유지한다(원안 유지).
- 그러나 매입합계는 주문 마진의 원가도 겸한다(약 20곳). 0만 두면 판매 주문 마진이 부풀고, 선매입 주문은 손실로 보인다.
  → 별도 칸 **재고 원가**를 두어 마진 = 합계 − 매입합계 − 재고 원가.
- 체크박스만으로는 재발한다 → 재고 있는 품목을 고르면 재고 출고 추천(확정은 직원), 재고 초과 출고 저장 차단, 출고 행 매입가 잠금, 확인 필요 목록.
- 용어: 품목 행 "재고" 칸 = 없음(기본) / 선매입 입고 / 재고 출고. '선매입 출고' 대신 **재고 출고**(판매 · 샘플 · 내부 사용 포괄).
  '선결제'(고객 선입금)와 혼동 방지로 화면에서는 "선매입 재고"처럼 붙여 쓴다.

## 사용자 결정 (2026-11-23)

1. 선매입한 물건은 **회사(사무실)로 들어온다** → 재고 출고 행은 발주 대상에서 제외(사무실에서 직접 발송).
2. **재고 원가를 따로 싣는 안**으로 시안 진행.
3. 비품 = 생필품 소모품(휴지 · 물티슈 · 커피 등, 매출과 무관) + **장비 자산(PC 등)도 포함**.
   쇼핑백 · 포장재는 비품이 아니라 **부자재**로 관리.
4. 기존에 '샘플'로 넣은 선매입 건의 남은 수량을 기초재고로 옮길지는 **확인 필요 — 지금 진행하지 않는다.**

## 손익 인식 시점 (2026-11-23 사용자 질문 · 결정)

## 시안 기준 A~D (2026-11-23 사용자 승인)

- A. 선매입 전용 주문은 매출처 "자사 재고(다올커머스)". 고객 주문과 함께 더 사 두면 같은 주문에 선매입 입고 행 추가.
- B. 재고 원가 = 선입선출(먼저 들어온 입고분 단가), 저장 시 고정. 두 입고분에 걸치면 배정 두 줄.
- C. 부자재는 주문마다 차감하지 않고 사용 기록 + 실사(주문 연결 선택).
- D. 비품은 인사 · 총무 영역 "비품 관리"(소모품 탭 + 장비 자산 탭). 선매입 재고 · 부자재 · 샘플 재고는 영업 · 주문 "재고 관리".

## 저장 구조 (안 — 1400번대)

- `erp_order_items` + `stock_role`(없음 · 선매입 입고 · 재고 출고) + `stock_cost`. `purchase_total` 뜻은 바꾸지 않는다.
- 재고 배정 표: 출고 행 ↔ 입고 행 · 수량 · 단가(선입선출 결과).
- 재고 조정 · 실사(선매입 재고 · 부자재 공용, 800 샘플 재고와 같은 방식).
- 부자재 품목 + 입고 · 사용 기록 / 비품 소모품(남은 수량 · 부족 기준 · 구입 기록) / 장비 자산 대장 + 이력.
- 요아럽 샘플 재고(800)는 데이터 이관 없이 "재고 관리" 화면의 탭으로만 묶는다.
- 마진 계산은 원가 = 매입합계 + 재고 원가로 한 함수에 모으고, 선매입 입고 행은 마진 집계에서 뺀다.

2. 시안 기준 A의 매출처 "자사 재고(다올커머스)"가 매출처 마스터에 있어야 선매입 전용 주문을 넣을 수 있다 — 없으면 주문 입력의 신규 매출처 등록으로 1회 등록(업체 다올커머스 · 지점 자사 재고 등, 이름은 사용자가 정함).
3. 실데이터 검증(1400 실행 후): 선매입 입고 1건 → 재고 관리에 입고분 확인 → 다른 주문에서 재고 출고 → 재고 원가 · 마진 · 발주 대기 제외 확인 → 출고 주문 취소 시 재고 복귀 확인.

### 추가 미결 (2026-11-23)
4. 품목 과세 · 면세 구분(미결 3 재확인) — 품목관리 트랙에 칸 추가 / 입고 행의 매입 계산서 구분 중 결정 필요. 그 전까지 전부 과세(÷ 1.1).
5. 샘플 재고 소진 비용에 "샘플 + 재고 출고" 행의 재고 원가를 더할지(지금은 안 더함 — 샘플 비용이 그만큼 적게 보임).
6. 재고 관리 화면 엑셀 다운로드(시안 ③ 버튼) — 2차와 함께.
