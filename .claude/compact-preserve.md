[대화 압축 보존 지침 — PreCompact 훅이 주입]

이 요약은 병행 트랙(총괄·회계·근태·개인화면·CRM)이 이어받는 인수인계 문서다.
다음 항목은 생략·축약하지 말고 반드시 보존할 것:

1. 사용자가 내린 결정·승인 내용 — 원문 취지 그대로 (예: "B안으로 진행", 임계값·명칭 결정)
2. 미결 항목과 사용자 액션 대기 목록 — 파일 대기, 마이그레이션 실행 대기, 확인 대기 등
3. DB에 가한 변경 작업과 검증 결과 (건수·표본 대조 결과 포함)
4. 마이그레이션 파일 번호·적용 상태
5. 진행 중 작업의 현재 상태와 바로 다음 단계
6. 사용자가 알려준 업무 규칙·용어 정의 (예: 상담자=고객과 상담한 직원)

또한 압축 후 첫 응답에서 수행할 것: 위 내용 중 저장소에 아직 기록되지 않은
중요 결정·미결 사항이 있으면 해당 트랙의 docs 문서(예: docs/accounting-track.md)
또는 CLAUDE.md에 기록하고 main에 반영한다.
